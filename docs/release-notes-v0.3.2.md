영상 우클릭 메뉴의 소리 기능을 구현했습니다.

- 음소거: 기존 음소거 기능과 연결하고 현재 상태를 체크 표시합니다.
- 음량 높이기 / 낮추기: 0–100% 범위에서 5%씩 조절하며 음량 바와 화면 안내에 반영합니다. 음소거 중 음량을 조절해도 음소거는 유지됩니다.
- 오디오 트랙 선택: 현재 미디어의 오디오 트랙과 `사용 안 함`을 선택할 수 있으며, 선택된 트랙에는 체크 표시가 나타납니다.
- 소리 메뉴와 오디오 트랙 선택 하위 메뉴는 클릭하거나 1초 이상 마우스를 올리면 펼쳐집니다.
- 오디오 트랙이 없으면 트랙 선택을 비활성화합니다. 하단 `…` 메뉴와 기존 단축키도 유지됩니다.
- 여러 창에서 같은 변환 자막을 사용할 때 캐시 파일을 덮어쓰다 발생하던 접근 오류를 수정했습니다.

Windows x64 POC 배포입니다. 포터블은 .NET과 LibVLC를 포함하며 첫 실행 시 사용자 캐시에 엔진을 추출합니다.

다운로드: `LightMediaPlayer-Portable-0.3.2.exe`, `LightMediaPlayer-Setup.exe`, `SHA256SUMS.txt`.
