- 전체 화면에서는 영상이 모니터 전체 영역을 사용합니다. 마우스를 위쪽 가장자리로 옮기면 제목 표시줄이 내려오고, 아래쪽으로 옮기면 재생 컨트롤이 올라옵니다. 가장자리를 벗어나면 해당 표시줄이 숨습니다. 표시줄이 움직이는 동안 영상 크기는 유지됩니다.
- 전체 화면에서 마우스를 2초간 움직이지 않으면 포인터가 숨고, 다시 움직이면 나타납니다.
- 방향키·Ctrl+방향키·Shift+방향키로 탐색하면 이동 안내에 전체 길이 대비 위치가 표시됩니다. 예를 들어 4분 영상의 1분 20초 지점에서는 `5초 앞으로, 00:01:20, (33%)`로 표시됩니다.
- 전체 화면에서 포인터가 하단 컨트롤 밖에 있을 때 방향키로 탐색하면 하단에 반투명 진행 막대가 나타나 1초 동안 서서히 사라집니다.
