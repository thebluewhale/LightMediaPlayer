재생 화면을 우클릭하고 **필터**를 선택하면 영상의 채도를 낮추거나 높이고, 밝기를 높일 수 있습니다. 클릭하거나 1초 이상 마우스를 올리면 하위 메뉴가 열립니다. 선택한 효과는 재생 중에 바로 적용되며, **필터 없음**을 선택하면 원본으로 돌아갑니다.

영상 위의 투명 영역에서도 우클릭 메뉴가 열리도록 마우스 입력 처리를 수정했습니다.

구현 단계에서 최종 채도 조정 전 Windows x64 빌드로 MKV·MP4 필터 전환, 원본 복원 및 두 창의 동시 재생을 확인했습니다. 최종 채도 값의 육안 확인은 미완료이며, 배포 단계에서는 기존 검사 결과를 재사용했습니다.
