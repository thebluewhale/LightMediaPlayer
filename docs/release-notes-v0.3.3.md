창 크기 변경 시 깜빡임을 유발할 수 있는 테두리 갱신 경로를 변경했습니다.

- WPF WindowChrome 대신 불투명한 네이티브 클라이언트 영역을 사용하는 테두리 처리를 적용했습니다. 제목 갱신 시 창을 잠시 숨기거나 크기 변경 때 창의 표시 영역을 다시 지정하는 경로를 제거했습니다.
- 8방향 크기 조절, 제목줄 드래그, 최소화·최대화, 전체화면과 이전 크기 복원을 유지합니다.
- 최대화는 모니터 작업 영역을 사용하고 전체화면은 모니터 전체를 사용합니다.
- 창 동작 전용 검사를 추가하고, 기존 트랙 검사가 비동기 변경 완료를 기다리도록 보완했습니다.

실제 마우스 드래그 화면에서 깜빡임이 사라졌는지와 모든 GPU·DPI 환경을 시각적으로 검증한 것은 아닙니다.

Windows x64 POC 배포입니다. 포터블은 .NET과 LibVLC를 포함하며 첫 실행 시 사용자 캐시에 엔진을 추출합니다.

다운로드: `LightMediaPlayer-Portable-0.3.3.exe`, `LightMediaPlayer-Setup.exe`, `SHA256SUMS.txt`.
