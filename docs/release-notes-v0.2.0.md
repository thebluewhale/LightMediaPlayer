Windows x64용 Light Media Player POC에 화면 안내, 이동시간 설정, 자석 정렬과 재생목록을 추가했습니다.

- 영상 우측 상단에 이동 방향·초·HH:MM:SS 위치와 변경된 음량을 2초 동안 표시합니다.
- 창을 모니터 작업 영역 가장자리 가까이 드래그하면 정렬합니다.
- 설정창에 기본 / 재생 / 자막 / 장치 / 코덱/필터 / 영상 / 소리 탭을 추가했습니다. 재생 → 이동시간 외의 탭은 비워 두었습니다.
- 방향키 / Ctrl+방향키 / Shift+방향키 이동시간을 1초 단위로 저장합니다. 기본값은 각각 5 / 60 / 300초입니다.
- 오른쪽 재생목록 패널 토글, 번호·파일명 표시, 단일 클릭 선택, 더블클릭 재생을 지원합니다.
- 이전·다음, 파일 추가·목록에서 삭제, 제목·크기·재생시간 정렬 및 매번 달라지는 셔플을 지원합니다.
- 정렬·삭제가 현재 재생을 바꾸지 않으며, 중복 파일도 항목별로 구분합니다.

다운로드:

- `LightMediaPlayer-Portable-0.2.0.exe`: 단일 실행 파일. 첫 실행 시 사용자 캐시에 엔진을 추출합니다.
- `LightMediaPlayer-Setup.exe`: 현재 사용자용 설치 프로그램.
- `SHA256SUMS.txt`: SHA-256 체크섬.

검증 범위와 남은 제한은 저장소의 `docs/testing.md`를 참고하세요. 실제 모든 모니터·DPI에서의 드래그 조작과 모든 미디어 형식은 검증하지 않았습니다. 실행 파일은 코드 서명되지 않았습니다.
