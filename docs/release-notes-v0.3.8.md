설치 EXE는 관리자 권한으로 모든 사용자용 플레이어를 설치합니다. 기본 경로는 `C:\Program Files (x86)\LightMediaPlayer`입니다. 기존 AppData 설치본은 별도로 관리됩니다.

설치 시 **Light Media Player (x64)** 를 Windows 기본 앱 후보로 등록합니다. **설정 → 앱 → 기본 앱**에서 원하는 확장자를 선택해 파일 연결을 지정할 수 있습니다.

구현 단계에서 설치 스크립트의 기본 경로와 확장자 112개의 등록 구성을 확인했습니다. 실제 설치 후 Windows 설정 목록에 표시되는지는 확인하지 않았습니다.
