- 플레이어에서 **Enter**를 누르면 전체 화면으로 전환되고, 다시 누르면 이전 창 크기로 돌아갑니다. 전체 화면에서 **Esc**를 누르면 이전 창 크기로 복원한 뒤 최소화됩니다.
- Windows 탐색기에서 여러 미디어 파일을 선택하고 **Enter**를 누르면 새 창 하나에서 첫 파일을 재생하고 나머지를 같은 재생목록에 넣습니다. 파일을 한 개씩 따로 열면 각각 새 창에서 재생되며, 기존 창의 재생도 계속됩니다.
- 앱의 파일 열기 대화상자나 재생 화면 드롭으로 여러 파일을 열 때도 한 목록으로 엽니다. 재생목록 영역에 드롭하면 현재 재생을 유지하고 목록 끝에 추가합니다.

탐색기에서 다중 선택 열기를 사용하려면 `LightMediaPlayer-Setup.exe`로 업데이트해 주세요. 설치 프로그램이 새 파일 열기 방식을 Windows에 등록합니다.

구현 단계의 개발 빌드에서 MKV·MP4 재생 검사 각 163개와 두 프로세스의 동시 재생 검사를 통과했습니다. Windows 셸의 열기 동작에서도 파일 두 개를 함께 열면 한 창에 두 항목이 생기고, 이어서 개별로 두 번 열면 창 두 개가 추가되는 것을 확인했습니다. v0.3.9 배포에는 이 검사 결과를 사용했습니다.
