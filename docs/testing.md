# POC 0.2.0 검증

최종 Windows x64 배포 EXE에서 두 프로세스 각각 74개 검사(총 148개), 동시 재생 구간 중첩, 정상 프로세스 종료를 확인했습니다. 설치·파일 해시 일치·제거 검사도 통과했습니다.

추가된 검증:

- 기본 이동시간 5/60/300초, 정수 입력 범위, 설정 저장과 다른 창의 상태 저장 시 이동시간 유지.
- 설정창의 정확한 7개 탭, 미구현 탭의 빈 내용, 잘못된 입력 시 저장 비활성화.
- 방향키·Ctrl·Shift 이동 명령의 실제 LibVLC 탐색, 빠른 연속 이동 누적.
- 이동 안내 문구, HH:MM:SS, 음량 퍼센트, 안내 자동 숨김.
- 음수 좌표 모니터의 좌측 상단, 작업 표시줄을 제외한 우측 하단, 임계 거리 밖에서 위치 유지.
- 재생목록 패널 표시·숨김과 창 너비 복원, 번호·파일명, 단일 선택 시 재생 유지.
- 항목 재생, 이전·다음, 제목·크기·실제 파싱 재생시간 정렬, 재생 중 항목·선택 유지.
- 8회 연속 셔플 모두 직전과 다른 순서.
- 파일 추가 시 재생 유지, 중복 항목 식별, 선택한 항목만 삭제, 재생 중 항목을 삭제해도 재생 유지.
- 정렬 중 편집 시 오래된 정렬 결과 무시, 빈 목록의 탐색 버튼 비활성화.
- 테스트 자체가 생성한 WPF 설정창·재생목록 PNG를 확인하여 설정 입력 줄 잘림을 수정하고 최종 배치를 확인했습니다.

새 원시 결과와 렌더링 이미지는 [test-results/v0.2.0](test-results/v0.2.0)에 있습니다. 실제 마우스 드래그로 모든 DPI/모니터를 확인한 것은 아니며, 자석 정렬은 좌표 계산과 네이티브 연결 코드 검증 범위입니다.

## 이전 POC 0.1.0 및 공통 검사

2026-11-21, Windows x64 환경에서 실행했습니다.

- Release 빌드: 컴파일 경고 0, 오류 0.
- 포터블: 독립된 두 EXE 프로세스에서 한글·공백 경로의 MKV와 MP4 동시 재생.
- 영상 출력: LibVLC의 `DisplayedPictures` 통계로 실제 프레임 출력 확인.
- 오디오: 디코딩 통계, 다중 트랙 선택, 음량, 음소거 전환.
- 재생 상태: 시작, 시간 증가, 일시정지 시 시간 유지, 재개, 정지, 처음부터 재시작, EOF, 종료 후 재시작.
- 탐색: 일시정지 중 탐색, 시간·길이, 소프트웨어 디코딩 재오픈 시 위치 복원.
- 자막: 외부 자막 로드, 트랙 표시·숨김, CP949 한글 변환.
- 화면 상태: 전체화면 진입·복원, 원본 비율 유지 설정, 오디오 전용 표시.
- 파일: 같은 폴더 자연 정렬 이전·다음, 로컬 M3U, 없는 파일을 열어도 현재 재생 유지.
- 오류: 손상 파일을 소프트웨어 디코딩으로 재시도한 뒤 오류 안내.
- 설정: 별도의 테스트 파일로 저장·로드 및 잘못된 JSON 복구. 사용자 설정은 변경하지 않음.
- 동시성: 두 프로세스의 실제 재생 구간 중첩 확인.
- 설치: 기본 앱·바탕화면을 변경하지 않고 작업 폴더에 설치, 설치된 EXE의 SHA-256 일치, 제거 후 앱 파일 삭제 확인.

원시 결과는 `docs/test-results`에 보관합니다. 테스트 중 생성한 파일의 경로만 포함하며, 사용자의 미디어 파일은 검사하지 않았습니다.

## 미검증 영역

- 운영체제 화면 캡처와 실제 키보드·마우스를 통한 모든 입력 경로, 각 DPI·다중 모니터 배치는 추가 수동 확인이 필요합니다. v0.2.0에서는 테스트 인스턴스의 WPF 컨트롤을 자체 렌더링하여 설정창·재생목록 배치를 검증했습니다.
- Windows의 기본 앱 선택을 변경하거나 탐색기의 실제 더블클릭 연결을 바꾸는 검사는 수행하지 않았습니다. 실행 인자 전달·독립 프로세스 재생은 검사했습니다.
- 설치 테스트에서는 파일 연결 등록 작업을 껐습니다. 연결 등록 스크립트는 컴파일 및 코드 검토로 확인했습니다.
- 모든 확장자·코덱·GPU·오디오 장치, 4K/HDR, 장시간 재생, DRM, 디스크 메뉴는 검증하지 않았습니다.
- 재생 안정성에는 LibVLC의 자동 디코딩 선택과 오류 시 소프트웨어 재시도가 포함되지만, 모든 하드웨어 문제에서 복구를 보장하지 않습니다.
