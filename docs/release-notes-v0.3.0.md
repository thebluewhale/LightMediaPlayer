재생목록 드래그 앤 드롭과 영상 우클릭 메뉴를 추가하고 설정 아이콘 잘림을 수정했습니다.

- 재생목록 영역에 드롭한 파일은 목록 끝에 추가합니다. 현재 재생 중인 영상과 일시정지 상태는 그대로 유지합니다.
- 하단 아이콘 버튼의 여백을 조정해 설정 아이콘이 온전히 표시되도록 했습니다.
- 영상 우클릭 메뉴: 재생 / 자막 / 영상 / 소리 / 필터 / 스킨 / 화면 비율 / 전체 화면 / 환경 설정.
- 재생 메뉴는 클릭 또는 1초 hover로 펼쳐집니다. 재생 / 일시 정지 / 이전 목록 재생 / 다음 목록 재생을 지원합니다.
- 전체 화면과 환경 설정은 클릭할 때만 실행합니다. 나머지 6개 카테고리는 추후 세부 기능을 추가할 비활성 항목입니다.
- 기존 자막·오디오 트랙 선택은 하단 `…` 메뉴에서 사용할 수 있습니다.

Windows x64 POC 배포입니다. 포터블은 .NET과 LibVLC를 포함하며 첫 실행 시 사용자 캐시에 엔진을 추출합니다.

다운로드: `LightMediaPlayer-Portable-0.3.0.exe`, `LightMediaPlayer-Setup.exe`, `SHA256SUMS.txt`.
