영상 우클릭 메뉴의 자막 기능을 구현했습니다.

- 자막 열기: 기존 외부 자막 파일 열기 기능과 연결했습니다.
- 자막 표시/숨김: 현재 자막을 숨기거나 다시 표시합니다.
- 자막 트랙 선택: 현재 미디어의 자막 트랙과 `사용 안 함`을 선택할 수 있으며, 선택된 트랙에는 체크 표시가 나타납니다.
- 자막 메뉴와 자막 트랙 선택 하위 메뉴는 클릭하거나 1초 이상 마우스를 올리면 펼쳐집니다.
- 미디어가 없거나 자막 트랙이 없으면 해당 동작을 비활성화합니다. 하단 `…` 메뉴의 기존 기능도 유지됩니다.

Windows x64 POC 배포입니다. 포터블은 .NET과 LibVLC를 포함하며 첫 실행 시 사용자 캐시에 엔진을 추출합니다.

다운로드: `LightMediaPlayer-Portable-0.3.1.exe`, `LightMediaPlayer-Setup.exe`, `SHA256SUMS.txt`.
