Windows x64용 Light Media Player 첫 POC입니다. C# / WPF / .NET 10 / LibVLC 기반이며, 별도 .NET·VLC 설치 없이 실행됩니다.

- 재생·일시정지·정지, 시간 표시, 구간 탐색, 음량·음소거.
- 파일 열기·드래그 앤 드롭, 한글 경로, 전체화면, 원본 비율 유지.
- 탐색기에서 새 파일을 열 때 독립 프로세스 실행. 기존 영상은 계속 재생.
- 기본 자막·인코딩 처리, 오디오·자막 트랙 선택.
- 이전·다음 파일, 기본 로컬 목록 읽기, 상태·오류 표시, 설정 기억, 소프트웨어 디코딩 재시도.
- 설정과 재생목록 확장 버튼은 표시만 합니다.

다운로드:

- `LightMediaPlayer-Portable-0.1.0.exe`: 설치 없이 실행. 첫 실행 시 사용자 캐시에 엔진 추출.
- `LightMediaPlayer-Setup.exe`: 현재 사용자용 설치. 기본 앱은 Windows에서 직접 선택.
- `SHA256SUMS.txt`: 파일 검증용 SHA-256.

MP4·MKV 재생 통합 검사, 동시 프로세스 재생, 설치·제거 검사를 통과했습니다. 상세 결과와 지원 범위는 저장소의 `docs/testing.md`, `docs/formats.md`를 참고하세요. 전체 확장자 지원과 모든 하드웨어 환경을 보증하는 정식 버전은 아닙니다. 실행 파일은 코드 서명되지 않았습니다.
