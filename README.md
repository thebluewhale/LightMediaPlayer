# Light Media Player

Windows x64용 동영상·음악 플레이어 POC. C# / WPF / .NET 10 / LibVLCSharp / LibVLC로 구현했습니다.

## 실행 파일

[GitHub Releases](https://github.com/thebluewhale/LightMediaPlayer/releases)에서 받습니다.

- `LightMediaPlayer-Portable-0.3.14.exe`: 설치 없이 실행하는 단일 EXE. .NET이나 VLC를 따로 설치할 필요가 없습니다.
- `LightMediaPlayer-Setup.exe`는 관리자 권한으로 모든 사용자용 플레이어를 설치합니다. 기본 설치 폴더는 `C:\Program Files (x86)\LightMediaPlayer`입니다.
- `SHA256SUMS.txt`: 배포 파일의 SHA-256 체크섬.

포터블은 실행 시 포함된 네이티브 라이브러리를 사용자 캐시에 추출합니다. 실행 파일 하나만 이동해 사용할 수 있지만, 실행 후 캐시·설정·로그가 사용자 프로필에 남습니다. 파일 추출이 전혀 없는 EXE나 설정까지 USB에 보관하는 방식은 아닙니다.

설치하면 **설정 → 앱 → 기본 앱**에 **Light Media Player (x64)** 가 후보로 등록됩니다. 원하는 확장자(예: `.mp4` 또는 `.mkv`)를 선택하고 기본 앱으로 지정하면 해당 파일을 더블클릭해 재생할 수 있습니다.

AppData에 설치된 기존 사용자용 설치본은 **설정 → 앱 → 설치된 앱**에 **Light Media Player 버전 …** 또는 **Light Media Player**로 표시됩니다. 새 설치본은 **Light Media Player (x64)** 로 구분되므로, 새 버전으로 전환한 뒤 기존 설치본만 선택해 제거할 수 있습니다.

## 구현된 기능

- 상단 제목 표시줄, 최소화·최대화·종료, 창 크기 조절.
- 창 테두리는 불투명한 Win32 클라이언트 영역과 네이티브 크기 조절을 사용합니다. 크기 변경 때 창 표시 영역을 다시 지정하거나 제목 갱신 때 창을 잠시 숨기는 WPF WindowChrome 경로를 사용하지 않습니다.
- 영상 표시, 원본 화면 비율 유지, 오디오 전용 파일 표시.
- 재생·일시정지·정지와 상태에 따른 재생 버튼 전환. 정지 후 재생은 처음부터 시작.
- 진행 바 클릭·드래그, 시간 표시, 키보드 구간 탐색.
- 이동·음량·재생 상태를 영상 오른쪽 위에 2초 동안 표시. 이동 안내에는 전체 길이 대비 이동한 위치를 정수 백분율로 표시합니다. 예를 들어 4분 영상의 1분 20초 지점에서는 `5초 앞으로, 00:01:20, (33%)`로 표시됩니다. 음량은 `75%` 형식입니다.
- 음량·음소거, 전체화면과 이전 창 크기 복원.
- 전체 화면에서는 영상이 모니터 전체 영역을 사용합니다. 마우스를 위쪽이나 아래쪽 가장자리로 옮기면 해당 표시줄이 영상 위로 미끄러져 나타나고, 가장자리를 벗어나면 다시 숨습니다. 화면 맨 아래의 반투명 진행 막대는 현재 재생 위치를 계속 표시합니다. 하단 컨트롤이 나타나면 진행 막대가 숨고, 컨트롤이 사라지면 다시 보입니다. 포인터는 2초간 움직이지 않으면 숨고 다시 움직이면 나타납니다.
- 창 드래그 중 모니터 작업 영역 가장자리에서 16 DIP 이내에 오면 자석처럼 정렬. 작업 표시줄을 제외하고 음수 좌표 모니터도 처리합니다.
- 파일 열기, 드래그 앤 드롭, 명령줄 파일 경로 처리, 한글·공백 경로.
- 탐색기에서 파일을 따로 열 때마다 새 창이 키보드 포커스를 받고 기존 영상은 계속 재생됩니다. 플레이어를 클릭할 필요 없이 Enter로 전체 화면을 전환하거나 방향키로 탐색할 수 있습니다. 여러 미디어 파일을 선택하고 Enter를 한 번 누르면 새 창 하나에서 첫 파일을 재생하고 나머지를 같은 재생목록에 넣습니다. 이 동작은 설치 프로그램으로 파일 연결을 등록한 뒤 사용할 수 있습니다. 앱의 파일 열기와 재생 화면 드롭에서도 여러 파일을 한 목록으로 엽니다.
- 영상이 끝나면 2초 후에 재생목록의 다음 파일을 재생합니다. 마지막 파일이 끝나면 같은 간격으로 첫 파일부터 다시 재생합니다. 재생 중인 파일 하나만 있으면 재생 완료 상태로 멈춥니다. 이전·다음 버튼은 목록의 양 끝에서 각각 비활성화됩니다. 단일 파일을 열면 해당 파일만 목록에 넣습니다.
- 동일 이름의 자막 자동 로드, 외부 자막 열기·드롭, 자막 켜기·끄기.
- UTF-8, UTF-16, CP949 텍스트 자막 처리. 원본 자막 파일을 수정하지 않고 변환본을 캐시합니다.
- 오디오·자막 트랙 선택: 하단 `…` 메뉴 또는 영상 우클릭의 `소리`·`자막` 메뉴.
- 영상 우클릭 메뉴에서 재생·자막·영상·소리·필터·화면 비율 및 트랙 선택 하위 메뉴는 클릭하거나 1초 이상 마우스를 올려두면 열립니다. 전체 화면과 환경 설정은 클릭하면 실행됩니다. 스킨은 비활성 상태입니다.
- `필터`에서 채도 낮추기, 채도 높이기, 밝기 높이기 중 하나를 선택하면 재생 중인 영상에 바로 적용됩니다. `필터 없음`을 선택하면 원본으로 돌아갑니다. 선택은 해당 창을 닫을 때까지 유지됩니다.
- `화면 비율`에서 원본 비율(기본값), 16:9, 16:10, 4:3을 선택하면 재생 중인 영상에 즉시 적용됩니다. 선택한 비율은 해당 창을 닫을 때까지 유지됩니다.
- `영상 → 비디오 트랙 선택`에서 현재 파일의 비디오 트랙을 전환합니다. 현재 트랙에는 체크 표시가 나타나며 비디오 트랙이 없는 파일에서는 선택 메뉴가 비활성화됩니다.
- 자막 메뉴: 자막 열기 / 자막 표시·숨김 / 자막 트랙 선택. 트랙 목록에는 현재 선택된 자막을 체크 표시하며 `사용 안 함`으로 끌 수 있습니다. 재생 중인 미디어가 없으면 자막 열기를 비활성화하고, 자막 트랙이 없으면 표시·숨김과 트랙 선택을 비활성화합니다.
- 소리 메뉴: 음소거 / 음량 높이기 / 음량 낮추기 / 오디오 트랙 선택. 음량은 0–100% 범위에서 5%씩 조절하며 화면 안내와 음량 바에 반영됩니다. 음소거 중 음량을 조절해도 음소거는 유지됩니다. 음소거·현재 트랙은 체크 표시하고, 오디오 트랙이 없으면 트랙 선택을 비활성화합니다.
- 로딩·버퍼링·일시정지·종료·파일 오류 표시와 프로세스별 로그.
- 음량·음소거·창 크기·위치 기억. 동시에 여러 창을 닫으면 마지막으로 저장한 창의 설정을 사용합니다.
- 하드웨어 디코딩 우선, 재생 오류 시 소프트웨어 디코딩 재시도. 메뉴에서 수동으로 소프트웨어 디코딩을 선택할 수도 있습니다.
- 기본 로컬 M3U/PLS/ASX/XSPF 목록 읽기. 재생목록 내부의 로컬 미디어를 이전·다음으로 이동합니다.

## 설정과 재생목록

설정 버튼으로 7개 탭(기본 / 재생 / 자막 / 장치 / 코덱/필터 / 영상 / 소리)을 엽니다. 현재 **재생 → 이동시간**만 구현되어 있고 다른 탭은 비어 있습니다.

- 방향키: 기본 5초, Ctrl+방향키: 기본 60초, Shift+방향키: 기본 300초.
- 직접 숫자를 입력하거나 ± 버튼으로 1초씩 조절합니다. 범위는 1–86,400초입니다.
- 저장하면 현재 창에 즉시 적용되고 다음 실행에도 유지됩니다. 취소하면 변경되지 않습니다.
- 다른 플레이어 창은 다시 활성화할 때 저장된 이동시간을 읽습니다. 창을 닫을 때 다른 창에서 저장한 이동시간을 덮어쓰지 않습니다.

오른쪽 아래 재생목록 버튼으로 오른쪽 패널을 표시·숨깁니다. 오른쪽에 여유 공간이 있으면 창도 넓어집니다. 전체 화면에서는 재생목록을 숨기고 영상이 오른쪽 공간까지 사용합니다. 창 모드로 돌아오면 전체 화면 진입 전의 재생목록 표시 상태를 복원합니다.

- `01. 파일명` 형식으로 표시하며, 단일 클릭은 선택만 하고 더블클릭은 해당 항목을 재생합니다. 재생 중인 항목은 강조색으로 표시합니다.
- ▲ / ▼ 및 Page Up / Page Down은 현재 재생목록에서 이전 / 다음 파일을 즉시 엽니다. Page Up은 첫 파일에서 마지막 파일로, Page Down은 마지막 파일에서 첫 파일로 이동합니다.
- 추가: 선택한 파일들을 목록 끝에 추가합니다. 추가만으로 재생을 바꾸지 않습니다. 같은 파일을 여러 번 넣을 수 있습니다.
- 재생목록 영역에 파일 드롭: 드롭한 파일들만 순서대로 목록 끝에 추가하며, 현재 영상과 재생·일시정지 상태를 유지합니다. 재생 화면에 드롭하면 파일을 여는 기존 동작을 사용합니다.
- 삭제: 선택한 항목만 목록에서 제거합니다. 디스크 파일은 삭제하지 않으며, 현재 재생 중인 항목을 지워도 재생은 계속됩니다.
- 정렬: 제목(자연 정렬), 파일 크기, 재생시간 오름차순 또는 셔플. 알 수 없는 크기·시간은 마지막에 놓습니다.
- 셔플은 항목이 2개 이상이면 직전 순서와 달라집니다. 정렬·셔플로 재생 중인 파일이 바뀌지 않습니다.
- 재생시간 분석은 별도 엔진/작업에서 수행합니다. 분석 중 목록을 수정하면 이전 정렬 결과가 새 목록을 덮어쓰지 않습니다.
- 재생목록은 각 창마다 독립적이며 앱 종료 후 목록 자체를 복원하지는 않습니다.

## 파일 형식과 제한

사용자가 요청한 확장자 목록은 파일 선택 필터와 설치 프로그램의 연결 후보에 포함됩니다. **확장자 등록은 실제 디코딩 지원 보증이 아닙니다.** 실제 지원은 LibVLC 3.0.24의 컨테이너·코덱·자막 지원에 따릅니다. DRM, 전용 형식, 디스크의 부속 파일은 별도 지원이 필요할 수 있습니다.

검증된 조합과 미검증 영역은 [형식 지원 범위](docs/formats.md), 검증 내역은 [테스트 결과](docs/testing.md)를 참고하세요. 설정창·재생목록의 자체 렌더링 이미지는 확인했습니다. 실제 모든 GPU·DPI·모니터 환경에서의 사용자 입력 검증은 수행하지 못했습니다.

## 데이터 위치

- 설정: `%LOCALAPPDATA%\LightMediaPlayer\settings.json`
- 엔진: `%LOCALAPPDATA%\LightMediaPlayer\runtime\<payload hash>`
- 자막 변환본: `%LOCALAPPDATA%\LightMediaPlayer\subtitles`
- 로그: `%LOCALAPPDATA%\LightMediaPlayer\logs\player-<pid>.log`
- .NET 단일 파일용 네이티브 추출 캐시는 .NET 런타임의 사용자 임시 경로를 사용합니다.

설치 제거는 앱 파일과 앱의 연결 등록을 제거합니다. 설정·캐시는 유지합니다. 로그에는 열었던 파일 경로가 포함될 수 있습니다. 앱은 로그를 업로드하지 않습니다.

## 빌드

Windows x64, PowerShell 7, 인터넷 연결이 필요합니다. SDK 10.0.404, LibVLC 3.0.24, LibVLCSharp 3.10.2, Inno Setup 7.1.1을 사용합니다.

```powershell
./scripts/bootstrap.ps1
./scripts/build.ps1
```

의존성은 `.tools`에, 배포 파일은 `artifacts/release/v<버전>`에 생성합니다. 도구와 배포 바이너리는 Git에 포함하지 않습니다. Inno Setup을 상업적으로 사용하려면 해당 도구의 사용 조건을 확인하세요.

`src/LightMediaPlayer/Assets/mediaplayericon.png`가 앱 아이콘 원본입니다. 원본을 교체한 뒤 Python과 Pillow가 설치된 환경에서 `python scripts/make-icon.py`를 실행하면 앱과 설치 프로그램이 사용하는 `player.ico`를 다시 생성합니다.

## 테스트

FFmpeg Windows 빌드를 `.tools/ffmpeg` 아래에 준비합니다. FFmpeg는 테스트 미디어 생성에만 사용하며 앱에는 포함하지 않습니다.

```powershell
./scripts/create-fixtures.ps1
./scripts/test.ps1
./scripts/test-resize.ps1
```

생성한 MP4·MKV를 두 프로세스로 동시에 실행하여 실제 LibVLC 재생·탐색·자막·트랙·오류·동시 재생과 설정·재생목록을 검증합니다. 결과 JSON은 `artifacts/test-results/v<버전>`에 생성됩니다. 테스트는 사용자의 설정 파일을 덮어쓰지 않습니다.

## 코드 구조

- `src/LightMediaPlayer/MainWindow.xaml`: 화면.
- `MainWindow.xaml.cs`: 재생 생명주기, 입력, 메뉴, 자막, 전체화면.
- `MainWindow.Interaction.cs`, `SettingsWindow`: 화면 안내, 이동 단축키, 설정창.
- `MainWindow.ContextMenu.cs`, `DelayedSubmenuItem.cs`: 영상 우클릭 메뉴, 클릭·1초 hover로 하위 메뉴 열기.
- `MainWindow.Playlist.cs`, `PlaylistEntry.cs`: 목록 편집, 현재 항목 식별, 비동기 정렬.
- `WindowMagnet.cs`: WM_MOVING 기반 모니터 작업 영역 자석 정렬.
- `PlayerWindowFrame.cs`: 네이티브 테두리 hit test, 제목줄 드래그, DPI별 최소 크기, 작업 영역/전체화면 크기 처리.
- `MediaFiles.cs`, `PlaylistFiles.cs`: 형식 분류, 파일명 비교, 로컬 목록 읽기.
- `PlayerSettings.cs`: 설정 로드·원자적 저장·손상 복구.
- `NativeRuntime.cs`: 단일 EXE의 엔진 추출. 추출 시에만 잠금을 사용하므로 다중 프로세스 재생을 제한하지 않습니다.
- `MainWindow.SelfTest.cs`: 명시적 테스트 인자로만 실행되는 통합 검사.
- `installer`: Inno Setup 설치 및 연결 등록.
